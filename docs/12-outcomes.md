# 12 — Outcomes & KPI Framework

No unsupported production metrics are claimed in this portfolio repository.

## Recommended KPI Baseline

| Dimension | KPI |
|---|---|
| Speed | end-to-end cycle time |
| Quality | first-pass acceptance rate |
| Efficiency | rework hours / return rate |
| Governance | approval SLA adherence |
| Control | % decisions with complete evidence |
| Exceptions | open exceptions by ageing |
| Adoption | active users / workflow completion |
| Automation | assisted tasks accepted vs edited |

## Measurement Approach

Capture baseline before rollout, measure by workflow stage after rollout, and compare like-for-like cohorts. Report both **median cycle time** and tail performance where volume supports it.
