# 05 — Process, Gates & Controls

## Control-Point Model

### Gate 1 — Intake
Validate mandatory business need, quantity, specification basis and ownership.

### Gate 2 — Specification / RFP
Check completeness, version, commercial fields and required approvals.

### Gate 3 — Publication Readiness
Confirm approval state and publication package before external tender handoff.

### Gate 4 — Evaluation
Separate evaluation responsibilities from approval authority and retain evidence.

### Gate 5 — Decision
Require authorised approval, rationale and timestamp.

### Gate 6 — Exception
Any rejection, revocation, deviation or SLA breach creates a tracked exception with owner and disposition.

## Segregation of Duties

The person preparing a procurement artefact should not automatically be the sole person approving the resulting decision. Role boundaries are explicit in the workflow.

## Audit Event Model

Every material event should capture:

`actor + role + action + object + previous state + new state + timestamp + evidence reference`
