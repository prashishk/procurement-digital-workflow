# 02 — As-Is to To-Be

## As-Is

`Requirement → Documents → Manual Review → Multiple Handoffs → Tender → Approval → Exception Follow-up`

Typical control gaps to address:

- inconsistent intake quality
- unclear ownership at handoffs
- late discovery of missing evidence
- fragmented status visibility
- manual exception tracking
- weak linkage between a decision and its supporting evidence

## To-Be

`Structured Intake → Validation Gate → RFP Workspace → Controlled Review → Tender Handoff → Evaluation → Approval Gates → Award / Exception → Immutable Audit Record`

## Product Principles

- **One workflow state** — every item has an explicit status.
- **One accountable owner** — each gate has an accountable role.
- **Evidence before decision** — approvals reference supporting artefacts.
- **Exception by design** — deviations enter a controlled workflow.
- **Human-in-the-loop** — automation recommends; authorised users decide.
