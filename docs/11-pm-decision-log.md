# 11 — PM Decision Log

| Decision | Rationale | Trade-off |
|---|---|---|
| Structured workflow over free-form tickets | improves control and analytics | higher initial design effort |
| Explicit approval gates | protects accountability | can increase cycle time if poorly configured |
| Exception workflow | makes deviations measurable | requires disciplined ownership |
| AI as assistive layer | reduces operational risk | less automation than autonomous agents |
| Evidence-linked decisions | improves auditability | requires stronger data model |

## PM Lens

A strong delivery manager does not optimise only for feature velocity. The target is **value delivered with controlled operational risk**.
