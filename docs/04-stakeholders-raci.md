# 04 — Stakeholders & RACI

## Stakeholder Model

| Role | Primary concern |
|---|---|
| Business / Procurement Owner | requirement quality and commercial outcome |
| Technical / Platform Team | architecture, integration and reliability |
| Finance / Control Function | financial and policy controls |
| Approving Authority | accountable decision |
| Evaluators | consistent and evidence-based evaluation |
| Vendors / External Parties | clear, controlled interaction |
| Audit / Oversight | traceability and evidence |

## RACI — High Level

| Activity | Procurement | Technical | Finance/Control | Approver | Audit |
|---|---|---|---|---|---|
| Requirement intake | A/R | C | C | I | I |
| Specification validation | A/R | C | C | I | I |
| RFP release readiness | R | C | C | A | I |
| Tender publication handoff | R | C | I | A | I |
| Evaluation | A/R | C | C | I | I |
| Final approval | C | I | C | A/R | I |
| Exception disposition | R | C | C | A | I |
| Audit review | C | C | C | I | A/R |
