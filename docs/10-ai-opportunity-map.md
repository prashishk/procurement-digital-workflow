# 10 — AI Opportunity Map

AI should remove repetitive cognitive work while keeping accountable decisions with authorised humans.

| Use case | AI role | Human control |
|---|---|---|
| Requirement quality | identify missing/ambiguous fields | user confirms correction |
| RFP drafting | generate first draft from structured inputs | procurement owner edits/approves |
| Specification check | flag potential duplicates/inconsistencies | technical reviewer decides |
| Compliance checklist | surface potentially relevant controls | control owner validates |
| Exception summary | summarise case history/evidence | approver reviews source evidence |
| Analytics | explain anomalies / ageing | manager determines action |

## Guardrails

- no autonomous approval
- no autonomous vendor selection
- source/evidence visibility
- confidence / uncertainty surfaced
- prompt and model version traceability where applicable
- sensitive-data controls
- human override recorded

**Principle:** AI accelerates preparation and analysis; governance remains deterministic and accountable.
