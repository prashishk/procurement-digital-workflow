# 09 — Delivery Roadmap

## Phase 0 — Discovery
Map stakeholders, policies, current workflow, pain points, data objects and control points.

## Phase 1 — Foundation
Deliver structured intake, workflow states, RBAC, approval matrix and audit events.

## Phase 2 — Core Procurement
Add specification/RFP workspace, publication handoff, evaluation and exception management.

## Phase 3 — Intelligence
Add dashboards, SLA analytics and controlled AI-assisted validation.

## Phase 4 — Scale
Harden integrations, observability, performance, security controls and operating model.

## Delivery Governance

Weekly delivery review → RAID review → dependency escalation → UAT readiness → release gate → post-release review.

Scope should be prioritised by **business value × risk × dependency**, not by feature volume.
